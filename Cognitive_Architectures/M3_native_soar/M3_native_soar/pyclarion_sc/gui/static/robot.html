What you see

  • Trail where the plan (top level, explicit rules) chose the path.
  • Trail where the habit (bottom level, trained network) chose the path.
  • Dirt. Rooms A and B are assigned; room C is not, and it is very dirty.
  • The charging dock, where the robot starts and must return.

How the robot decides, every 3 steps

  1. Motivational subsystem: each drive's strength is stimulus × deficit (Eq. 5). The achievement deficit can fall with time on task (Eq. 6).
  2. Metacognitive subsystem: the strongest goal is chosen (Eq. 7) and kept until done or clearly overridden.
  3. The goal's value sets the utility of each explicitness level, U = level × (α·value(g) − c), and a level is drawn from a Boltzmann distribution.
  4. Action-centered subsystem: with probability equal to explicitness the plan acts; otherwise the habit acts.
  5. A safety reflex (battery below 8%) sends the robot to the dock, outside self-control.
